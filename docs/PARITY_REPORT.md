# Parity report: BitlyIsDead vs Bitly (QA pass of 2026-10-15)

23 findings from the hands-on QA pass (8 high, 7 medium, 8 low). Each is **Fixed** or a **Justified exception**. Screenshots live in `docs/qa/2026-10-15/` as `before-*` (main before this work) and `after-*`. Verification is a Playwright script per area in `scripts/e2e-*.mjs` plus `npm run shots` (production build smoke).

**How the [gk] items were checked.** The QA browser was not signed in to Bitly and no throwaway Bitly account was created (same approach as the other IsDead clones). Bitly's app behaviour was read from its public Help Center on 2026-10-15 (links filters and Active/Hidden view, hide/unhide, tags, the create flow with domain/back-half/UTM/QR toggles, QR customisation options and error-correction level H, sign-up flow) and its public pricing page (prices and the annual/monthly toggle). Where the Help Center did not confirm something it is marked below.

## Extra checks the QA pass asked for

- **390 px layout:** landing, pricing, login, app Home and Links have no horizontal scroll (`scripts/qa-shots.mjs`, `after-m-*.png`). Fixed a login column overflow and the mobile sidebar overflow found on the way.
- **Link expiry:** create flow and details page set it; expired links return 410 (`tests/unit/linkstore.test.ts`, `npm run shots`).
- **Clipboard copy content:** `origin + /bitlyisdead/s/<code>` (create flow copies on create; Copy buttons on Home, Links, details, QR, pages).
- **SVG download:** QR SVG via the QR detail page (browser download, asserted non-empty with the right filename) and `/api/qr/<code>` (plain) — `e2e-qr.mjs`, `npm run shots`.
- **Google/Apple/SSO buttons:** Apple and SSO removed (never worked, IsDead rule); Google works where Firebase is configured (not testable on the local file store; the hosted deploy has the keys).
- **Hero callback surviving login:** verified for the guest path; the login path keeps the full path in `callbackUrl` (`app/login/page.tsx` strips/re-adds the base path).

## Needs a human decision

2. **Custom-domain routing** stays self-hosted-only unless the hub gets a wildcard host.
3. **Growth monthly price ($35)** should be eyeballed on bitly.com before the pricing PR merges.
